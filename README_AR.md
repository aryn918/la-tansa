# تطبيق لا تنسى — مشروع أندرويد

نسخة أولية عملية (Android / Java) بواجهة عربية وثيمين، مع تخزين محلي SQLite وتنبيهات محلية عبر AlarmManager.

## بناء APK من الهاتف فقط عبر GitHub Actions
1. نزّلي ملف ZIP وافتحيه/استخرجيه على هاتفك.
2. أنشئي مستودعاً جديداً على GitHub من المتصفح.
3. ارفعي **محتويات مجلد `la_tansa_app`** إلى جذر المستودع (وليس مجلد `la_tansa_app` كطبقة إضافية).
4. افتحي تبويب **Actions** ووافقي على تفعيل Actions إن طُلب.
5. اختاري **Build La Tansa APK** ثم **Run workflow**.
6. بعد نجاح البناء، افتحي نتيجة التشغيل وانزلي إلى **Artifacts** ثم نزّلي `la-tansa-debug-apk`.
7. استخرجي ملف ZIP الناتج، ثم افتحي `app-debug.apk` وثبتيه. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

لا تحتاجين إلى كمبيوتر؛ عملية بناء APK تتم على خوادم GitHub. يلزم اتصال إنترنت فقط أثناء رفع المشروع وتنزيل APK. بعد تثبيت التطبيق، تعمل المهام والتنبيهات محلياً دون إنترنت.

## ملاحظات
- لا يحتاج التطبيق إلى اتصال إنترنت أثناء الاستخدام، ولا يطلب صلاحية إنترنت.
- عند أول تشغيل، اسمحي بالإشعارات.
- على بعض أجهزة أندرويد قد يلزم السماح بالتنبيهات الدقيقة أو استثناء التطبيق من تحسين البطارية لضمان أفضل التزام بالمواعيد.
- التكرار الشهري في هذه النسخة محسوب كفاصل 30 يوماً، وليس كتاريخ مطابق في كل شهر.
- هذه نسخة أولية؛ اختبري التنبيهات على جهازك قبل الاعتماد عليها للمواعيد الحساسة.
